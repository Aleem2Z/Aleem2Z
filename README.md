## 🚀 About me

I'm a software engineer at **ByteTuned Technologies**. I work across the stack with TypeScript and PHP, building features, fixing bugs, and finding ways to make the code simpler.

- 🛠️ I care about readable code, useful products, and reusing what's already there.
- 🤖 I enjoy building AI-powered tools and automating repetitive work.
- 🎨 I have a soft spot for retro interfaces and playful web experiences.
- 🏓 Away from the keyboard: table tennis, anime, and TV shows.

## 🌟 Personal projects

- **[ByteScore](https://bytescore.app)** — Exam prep for HEC's National Skills Competency Test, with quizzes and mock exams.
- **SkillSnaps** — An AI-powered website builder that turns an idea into a multi-page site.
- **Autobank** — A digital banker for tabletop Monopoly, with shared rooms, live balances, and transfers between players.
- **JigglyList** — An anime list tracker I built in vanilla PHP to learn the language from the ground up.
- **[aleem.codes](https://aleem.codes)** — My portfolio, featuring an interactive Windows 95 desktop and a Konami code easter egg.
